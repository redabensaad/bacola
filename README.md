# Bacola Shopping Center

Angular 16 e-commerce showcase application inspired by a premium WordPress theme, demonstrating modern Angular architecture, reactive state management, and advanced frontend development patterns.

🔗 **Live Demo:** https://redabensaad.github.io/bacola/

## Key Features

* **Angular 16 Implementation:** Demonstrates modern Angular features and best practices.
* **MVVM Architecture:** Structured and maintainable application design using NgModules.
* **Reactive State Management:** NgRx-powered state handling for currency and location settings.
* **Optimized Performance:** 100% of components use the OnPush change detection strategy.
* **Modern UI Components:** Built with the NgZorro component library.
* **Responsive Design:** E-commerce user interface adapted for multiple screen sizes.
* **Static Frontend Showcase:** No backend dependency, focused entirely on frontend architecture and user experience.
